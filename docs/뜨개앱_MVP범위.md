# 뜨개 앱 MVP 범위 정리

## 프로젝트 개요
- **타깃**: 커뮤니티/공유 기능보다 혼자 뜨개하며 도안 작성에 어려움을 느끼는 시니어
- **운영 원칙**: 개발·운영 전부 무료 (서버 비용 최소화, 로컬 저장 우선)
- **차별화 지점**: "카운터 + 도안 뷰어 + 도안 작성"을 하나의 무료 앱에서 제공 (경쟁 앱들은 대부분 이 셋 중 하나만 강함)

---

## Phase 1 — MVP (반드시 있어야 출시 가능)

### 1-1. 단수/코수 카운터
- 카운터 여러 개 동시 운영 (본판/소매 등 파트별 구분)
- +1 / -1 / 리셋
- 반복 구간 카운터 (예: "8단 반복 × 5회")
- 자동 저장 (앱을 꺼도 마지막 값 유지)

### 1-2. 도안 보관함 (뷰어)
- PDF/이미지 도안 불러오기
- 도안 위에 현재 위치 표시(하이라이트) — 손으로 짚거나 펜 표시할 필요 없게
- 프로젝트별로 도안 여러 개 관리

### 1-3. 게이지 계산기
- 스와치 코수/단수 입력 → 10cm당 코수·단수 자동 환산
- 이후 도안 작성 기능(Phase 2)의 계산 기준값으로 저장

### 1-4. 바늘/실 굵기 변환기
- mm / US / UK / JP 표기 상호 변환
- 시니어에게 익숙한 표기(JP 등) 기준으로도 조회 가능

### 1-5. 기본 프로젝트 관리
- 프로젝트 생성/보관/완료 처리
- 파트별(앞판/뒷판/소매 등) 구분

---

## Phase 2 — 핵심 차별화 (도안 작성 툴)

### 2-1. 격자 기반 도안 캔버스
- 가로=코, 세로=단인 격자
- 격자 칸 크기 확대/축소 (시니어 가독성)
- 실행 취소(undo) 필수

### 2-2. 표준 기호 팔레트
- 자유 드로잉이 아닌, 표준 기호(JIS 계열)를 선택해 칸에 찍는 방식
- 기호 클릭 시 뜻풀이 툴팁 제공 (암기 없이 사용 가능하게)

### 2-3. 문자식 ↔ 차트식 자동 변환
- 격자에 기호를 채우면 "1단: 겉뜨기 5, 안뜨기 3…" 형태 문장 자동 생성
- 기호가 어려운 사용자를 위한 보조 확인 수단

### 2-4. 증코/감코 계산기
- 시작 코수 → 목표 코수 → 적용 단수 입력 시, 언제 몇 코씩 줄일지 자동 계산해 격자에 반영

### 2-5. 반복 구간 지정 → 카운터 연동
- 격자에서 구간을 지정하면 Phase 1의 반복 카운터에 자동 반영

---

## Phase 3 — 확장 (선택적, AI 활용)

- 사진/PDF 도안을 앱이 인식해 카운터 초기값·차트 초안 제안 (Grok 등 무료 API 활용, 필수 기능 아님)
- 완성 이미지 미리보기(배색 도안 시뮬레이션)
- 실 소모량 계산기
- 배색(색칠) 모드

---

## 이번 범위에서 제외 (Out of Scope)
- 커뮤니티/공유/소셜 기능
- Ravelry 등 외부 도안 라이브러리 연동
- 유료 구독 모델 (전부 무료 운영 원칙)

---

## 기술 방향 메모
- 데이터: 기기 내 로컬 저장 우선, 백업만 무료 티어 클라우드(Firebase/Supabase) 활용
- 프레임워크: React Native 또는 Flutter (1개 코드로 iOS/Android 대응)
- AI 기능은 Phase 3에서만, 무료 API 한도 내 보조 기능으로 한정
